# Requirements

- PHP 8.4
- Laravel 12 or 13
- Inertia 2 or 3
- Vue 3.5
- Node.js only if you customise the Vue kit and run your own build — see [Installation](/getting-started/installation)

Multi-database tenancy additionally needs `stancl/tenancy` ^3.10.

There is no Packagist package and no npm registry package. PanelKit installs
from a GitHub Composer VCS repository — see [Installation](/getting-started/installation)
for why, and exactly what that means for your `composer.json`.
